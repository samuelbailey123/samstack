# Lessons

Mistakes already made once, one line each, dated. Read the lines that match your task; delete a line once a check enforces it.

- **A secret shown once goes clipboard to file** (2026-10-06). A secret a dashboard shows once never needs to pass through the agent's context: the user clicks Copy and the value goes straight from the clipboard to a file. *Apply:* run `umask 077; printf 'KEY=%s\n' "$(pbpaste | tr -d '\r\n')" >> ~/.config/<app>/<name>.env`, then `pbcopy </dev/null`, and verify by printing only names and lengths (`awk -F= '{print $1, length($2)}'`).
- **A strict csp kills direct to storage uploads** (2026-09-10). connect-src 'self' makes a presigned browser PUT die as "Failed to fetch" with nothing server-side and a correct CORS preflight; prove it with a control fetch to a CORS-friendly origin. *Apply:* when a cross-origin fetch fails with no HTTP status, run a control from the same page against an origin known to allow CORS (`fetch('https://api.github.com/zen')`); if that fails too, it is CSP. Any direct-to-storage design needs the storage origin in `connect-src` and, for images loaded via a redirecting route, `img-src`.
- **Rotate a credential after the redeploy not before** (2026-09-10). Vercel functions read env at deploy time; changing a variable does nothing until a redeploy, so deleting the old credential first breaks production until then. *Apply:* rotate in three steps: add the new credential, `vercel redeploy` the current production deployment (or ship a normal deploy), verify with a real request, then revoke the old one. Never revoke first.
